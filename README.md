# Автомобільний каталог

Фінальний мінімалістичний React-проєкт для керування каталогом автомобілів.

## Можливості

- Перегляд інформації про автомобіль.
- Фільтрація за виробником, роком, кольором, об'ємом двигуна і ціновим діапазоном.
- Додавання нового автомобіля.
- Редагування існуючого автомобіля.
- Видалення автомобіля.

## Запуск

```bash
npm install
npm run dev
```

## Збірка

```bash
npm run build
```
